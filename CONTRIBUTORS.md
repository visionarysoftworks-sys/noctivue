# Contributors

Noctivue is developed in the open by the project maintainers and
community contributors.

## Current project maintainer

- `visionarysoftworks-sys` — language design, compiler, runtime, tooling,
  examples, and project direction

## How to contribute

Contributions are welcome in all areas of the project, including:

- Noctivue language design and compiler implementation
- standard library and runtime work
- CLI, package manager, formatter, and LSP tooling
- VS Code support
- examples such as Nightshade
- documentation and tests

Before making a substantial change, open an issue or discussion so the
design can be coordinated with the current development phase. Small
documentation, test, and bug-fix changes can be submitted directly.

Please keep changes focused, document behavior that is still
experimental, and run the smallest relevant existing test suite before
submitting a pull request.

All contributors retain copyright in their contributions and license
them under the repository's MIT License when they submit them to the
project.
